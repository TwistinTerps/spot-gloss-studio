# Spot Gloss Studio — Mac (Safari)

Adobe-vector UV studio. One HTML file. No install.

## Open it (any MacBook / Air / Pro)

**Run in Safari (no download):**  
https://twistinterps.github.io/spot-gloss-studio/

**Direct download (Save the file, then Open With Safari):**  
https://github.com/TwistinTerps/spot-gloss-studio/releases/latest/download/Spot-Gloss-Studio.html

If macOS blocks the file: right-click → Open With → Safari.

Safari only. Place a PNG, JPG, or SVG logo. Image Trace is a draft — Pen (P) is the plate. Export Plates puts a zip in Downloads for Illustrator.
